## 재현 명령

```sh
# 공개 색인을 읽고 캐시한 원본으로 개발용 부분 카탈로그를 생성
npm run catalog:fetch
```

수집 파일은 `.local/hanja/`에 보관합니다. 기존 버전의 재반입은 거절되며 트랜잭션 전체가 롤백됩니다. 색인/페이지 버전·날짜·개수 불일치, 중복, 독음 불일치, 외부 도메인 URL, 잘못된 획수를 거절합니다. 원획 누락은 계산에 사용할 수 없으므로 제외하고 보고합니다. 부분 자료를 `verified`로 등록하는 것도 거절합니다.

실제 HTTP 검증 시각: `2026-11-05T05:53:38.743Z` (한국 시간 14:53). 58개 독음 응답의 모든 2,941개 항목이 반입본과 일치했고, 이름 계산·필터·빈 결과·403·400 검증이 통과했습니다. 실행 결과는 `.local/verification/hanja-http.json`, 사람이 읽는 결과는 `.local/verification/hanja-http.html`에 있습니다. 이는 FE 화면 E2E 또는 운영 배포 검증이 아닙니다.
